## 🚨 Common Issues & Solutions

### Issue: Sitemap not found
**Solution:** Check route in `routes/web.php` and controller exists

### Issue: Pages not indexed
**Solution:** Submit sitemap to Search Console, check robots.txt

### Issue: Slow loading
**Solution:** Enable compression, optimize images, use CDN

### Issue: Poor mobile score
**Solution:** Check responsive design, optimize for mobile

### Issue: Social media preview not showing
**Solution:** Clear cache in Facebook/Twitter debugger tools

### Issue: Structured data errors
**Solution:** Validate with Rich Results Test, fix JSON-LD syntax
